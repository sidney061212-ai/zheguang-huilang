# 棱镜光线 / Prism Lab

《棱镜光线 / Prism Lab》是一个面向微信小游戏平台的轻量单机益智小游戏。玩家通过调整镜子、三棱镜等光学元件，引导光线命中目标点。第一版目标是成功上线和保持工程可持续开发，不做登录、排行榜、广告、支付、后端或隐私采集。

## 技术栈

- 微信小游戏
- TypeScript
- Canvas 2D
- 自研轻量游戏框架
- 本地关卡与本地存档

## 目录结构

```text
docs/       正式项目文档、上线清单、审核风险清单
prompts/    可直接复制给 Codex 的后续任务提示词
minigame/   微信小游戏工程
archive/    历史 demo 与原型归档
```

## 如何运行

当前阶段是工程骨架。请用微信开发者工具导入 `minigame/` 目录。正式 AppID 尚未配置时，可先使用测试号或微信开发者工具的小游戏调试能力。

## 如何开发

核心代码位于 `minigame/src/`：

- 玩法规则写在 `rules/`
- 渲染写在 `renderer/`
- UI 写在 `ui/`
- 平台能力写在 `platform/`
- 关卡数据写在 `levels/`

wx API 只允许出现在 `platform` 层，业务逻辑通过接口调用平台能力。

## 如何提交 Codex 任务

从 `prompts/` 中选择下一步任务，把完整 prompt 发给 Codex。每次任务需要更新代码或文档，并在完成后提交 Git commit。

## 如何让 GPT 审核

把交付报告、相关 docs 文件和 Git commit hash 发给 GPT，重点审查：

- 架构是否过重
- 分层是否合理
- 文档是否完整
- 是否符合轻量小游戏目标
- 是否有微信审核风险
- 是否方便后续 Codex 继续开发
