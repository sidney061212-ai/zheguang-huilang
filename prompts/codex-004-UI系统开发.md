# Codex 任务 004：UI 系统开发

请开发第一版 Canvas UI 系统。

目标：
- 首页：标题、开始游戏、关卡选择、设置入口。
- 关卡选择：显示已解锁关卡和返回按钮。
- 游戏顶部栏：关卡名、重开按钮、暂停按钮。
- 胜利弹窗：下一关、重玩、返回关卡选择。
- 设置入口：音效开关、背景音乐开关、版本信息。

要求：
- UI 走 `minigame/src/ui/` 组件，不把按钮逻辑散落到场景。
- UI 事件通过 `EventBus` 通知音效和场景。
- 不做大屏风、复杂营销页或重度动效。
- 保持触摸区域清晰，适配常见手机屏幕。

验收：
- 首页到游戏页流程可走通。
- 胜利后弹窗可操作。
- 设置页可切换静音状态。
