# v0.1 Decisions

- Prism is placeholder only in v0.1; no playable prism levels.
- Concentrator is placeholder only in v0.1.
- Mirror is the only v0.1 player tool.
- Light distance decays by actual traveled path length.
- Raycast must use real geometry, not fake path animation.
- No ads, login, ranking, payment, backend, or sharing incentives.
- `wx` API is allowed only in `minigame/src/platform/`.
