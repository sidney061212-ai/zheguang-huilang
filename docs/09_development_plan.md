# 《折光回廊》开发计划

## Phase 1：正式策划文档
验收：
- 12 份文档完整
- 方向统一
- 核心术语统一
- 没有 PC / 键鼠 / 旧设定污染

## Phase 2：技术架构文档
验收：
- 明确微信小游戏技术路线
- 明确渲染方案
- 明确关卡数据结构
- 明确光线计算方式
- 明确状态管理

## Phase 3：项目骨架
验收：
- 能在微信开发者工具打开
- 有基础目录结构
- 有画布
- 有主循环
- 有基础输入

## Phase 4：第 1 关垂直切片
验收：
- 光源能发光
- 镜子能拖动
- 镜子能旋转
- 光线能反射
- 出口能判断通关
- 能重置
- 能显示简单结算

## Phase 5：3 关验证
验收：
- 连续反射
- 障碍绕行
- 三星目标

## Phase 6：6 关基础 MVP
验收：
- 光能衰减
- 聚光点
- 固定镜
- 本地记录

## Phase 7：12 关首版
验收：
- 吸光块
- 分光聚能点
- 汇光出口
- 颜色出口
- 首页
- 关卡页
- 通关页
- 设置页

## Phase 8：打磨与上线前检查
验收：
- 真机测试
- 性能检查
- 包体检查
- 体验检查
- 文档与实现一致

## 节奏原则
- 每个阶段都要有独立验收标准，不跨阶段偷做功能。
- 先确认玩法成立，再扩展关卡数，再补包装页面。
- 文档、实现、测试三者必须保持同一版本认知，避免后续返工。
