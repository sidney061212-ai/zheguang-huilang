# 棱镜光线 / Prism Lab 产品需求文档 PRD

## 游戏一句话介绍

玩家调整镜子和三棱镜，引导光线经过反射与分光后命中目标点，解开一组轻量光学谜题。

## 目标用户

- 喜欢短时益智、解谜、物理直觉类小游戏的微信用户。
- 希望在 1 到 3 分钟内完成一关、获得清晰反馈的休闲玩家。
- 对光线、镜面反射、颜色分光有好奇心的学生或泛科普用户。

## 用户核心动机

- 通过拖动和旋转元件，让路线从混乱变得清晰。
- 看到光线实时反馈，获得“我调对了”的即时满足。
- 逐关解锁新规则，形成低压力的学习和挑战节奏。

## 核心玩法循环

1. 进入关卡，观察光源、目标点和障碍布局。
2. 调整可操作元件，例如镜子或三棱镜。
3. 系统实时重新计算光路并渲染结果。
4. 光线命中目标点后显示胜利反馈。
5. 玩家进入下一关或重开寻找更优解。

## 页面结构

- 首页：项目标题、开始游戏、关卡选择、设置入口。
- 关卡选择：显示已解锁关卡、当前进度、返回首页。
- 游戏页：Canvas 主玩法、顶部关卡信息、重开、暂停或设置入口。
- 胜利弹窗：过关反馈、下一关、重玩。
- 设置页：音效开关、背景音乐开关、版本信息。

## MVP 功能列表

- 本地关卡配置和关卡加载。
- 光源发射光线。
- 镜子反射。
- 三棱镜白光三分光。
- 目标点命中检测。
- 重开和下一关。
- 本地解锁进度。
- 基础音效开关。
- Debug 开关，开发期可打印光线和分光日志。

## 非 MVP 功能列表

- 登录、排行榜、好友对战。
- 广告激励、内购、支付。
- 在线关卡库、UGC 编辑器。
- 复杂剧情、角色养成、皮肤商城。
- 云存档和数据分析。

## 验收标准

- 玩家不看说明也能通过前 3 关理解拖动、反射、分光。
- 三棱镜任意场景不会把 3 条彩色光继续分裂成 9 条。
- 每关可以在 30 秒内重开并继续尝试。
- 低端真机操作无明显卡顿，目标帧率 30 FPS 以上，理想 60 FPS。
- 提交审核前确认无登录、无网络请求、无隐私采集、无诱导分享。
