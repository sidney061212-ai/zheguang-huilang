# 微信小游戏上线清单

## AppID / 项目配置检查

- 确认正式 AppID 已填入 `project.config.json`。
- `compileType` 为小游戏。
- 体验版和正式版使用正确项目名称。
- 不提交本地调试路径和无关生成物。

## 名称、图标、简介

- 名称：棱镜光线 / Prism Lab。
- 图标需原创或具备授权。
- 简介突出单机益智、光线解谜，不夸大收益。

## 类目

优先选择休闲、益智、解谜相关类目，按微信后台可选项最终确认。

## 隐私说明

第一版不登录、不联网、不采集隐私。隐私说明中应明确仅使用本地存储保存关卡进度和设置。

## 用户协议

若微信后台要求，应准备简短用户协议，说明游戏为单机娱乐产品，不涉及账号、支付和个人数据上传。

## 体验版测试

- 微信开发者工具模拟器测试。
- iOS 真机测试。
- Android 真机测试。
- 低端机或旧系统测试。
- 首次进入、重开、过关、设置静音全部覆盖。

## 真机测试

重点检查触摸坐标、Canvas 缩放、音频播放、横竖屏、返回前台、后台恢复、低电量模式表现。

## 提交审核前检查

- 关闭 Debug 日志。
- 确认无网络请求。
- 确认无诱导分享文案。
- 确认无广告、支付、登录入口。
- 检查素材版权。
- 检查包体大小和启动速度。

## 发布后检查

发布后用正式入口完整玩前 3 关，确认版本号、设置、存档正常。记录用户反馈，下一版只针对明确问题迭代。
