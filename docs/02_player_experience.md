# 《折光回廊》玩家体验设计

## 1. 第一眼体验
- 玩家一眼看到左侧光源、右侧出口、中间障碍，理解“我要把光送过去”。
- 画面首屏不堆叠复杂按钮，核心关卡区域优先展示。
- 光源与出口要足够醒目，镜子与障碍物的功能差异在视觉上就能被区分。

## 2. 学习曲线
| 学习阶段 | 目标 | 关键收获 |
| --- | --- | --- |
| 第 1 关 | 只学镜子反射 | 知道拖动和旋转镜子可以改变光线路径 |
| 第 2 关 | 学连续反射 | 理解一条通路可能需要两面镜子配合 |
| 第 3 关 | 学障碍绕行 | 知道直线最短不一定可行，要绕开阻挡物 |
| 第 4 关 | 学光能衰减 | 理解路线长度会影响是否能通关 |
| 第 5 关 | 学聚光点 | 理解聚光点是补能中继点，而不是单纯检查点 |
| 后续关卡 | 学固定镜、吸光块、分光聚能点 | 逐步进入优化与多路规划 |

## 3. 上头点
- 第一次通关很容易，玩家可以快速建立信心。
- 拿三星需要优化，通关后仍然有继续调整的理由。
- 镜子少一面就更爽，优化结果能被玩家立刻感知。
- 光能剩余更高会带来成就感，形成“这次更干净”的满足感。
- 看到“还差一点就到出口”会想调整，因为问题可见、解法也看起来近在眼前。

## 4. 挫败感控制
- 这个游戏不应该重惩罚。
- 未通关时不给强烈负反馈，而是告诉玩家“光路还没连通”。
- 玩家不需要重新进入关卡，失败后可以立刻继续拖动镜子调整。
- 若光线熄灭，应直接高亮最后一段路径和原因，帮助玩家继续尝试，而不是打断节奏。

## 5. 复玩动力
- 三星评价
- 最少镜子记录
- 最佳剩余光能记录
- 每关最优解提示
- 后期每日挑战

## 6. 文案风格
不要写“失败”。建议统一使用以下表达：
- 光路未连通
- 光能不足
- 还差一次反射
- 试试减少一面镜子
- 光已抵达
- 完美折光

## 7. 体验节奏要求
- 首页到进入关卡的路径要短，首次进入尽量不超过两次点击。
- 单关内的可视反馈必须即时，镜子移动或旋转后，玩家应立即看见新的光路结果。
- 通关结算控制在短反馈长度内，让玩家能快速进入下一关或马上重试争三星。
