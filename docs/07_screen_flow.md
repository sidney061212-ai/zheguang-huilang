# 《折光回廊》页面流程

## 1. Loading / Boot
- 加载资源，进入首页。
- 仅显示必要的品牌与资源准备状态，不在此页讲解复杂规则。

## 2. Home 首页
展示：
- 游戏标题《折光回廊》
- 主视觉光球
- 开始游戏
- 继续关卡
- 设置
- 本地最高星数

页面职责：
- 让玩家立刻理解这是一个轻量、清亮的解谜产品。
- 为首次进入提供“开始游戏”，为回流玩家提供“继续关卡”。

## 3. LevelSelect 关卡选择
展示：
- 关卡节点
- 每关星级
- 已解锁 / 未解锁
- 当前章节
- 返回首页

页面职责：
- 明确展示进度与复玩价值。
- 允许玩家回到已通关关卡继续冲三星。

## 4. Gameplay 游戏页
展示：
- 当前关卡
- 三星目标
- 光能状态
- 镜子数量
- 重置
- 提示
- 关卡区域
- 镜子工具栏

页面职责：
- 把主要注意力集中在平面光路关卡区域。
- 保持“看图、拖镜、旋镜、立刻看到结果”的主循环。

## 5. ClearResult 通关页
展示：
- 光已抵达
- 星级
- 使用镜子数量
- 剩余光能
- 是否新纪录
- 下一关
- 重新挑战
- 返回关卡

页面职责：
- 用短反馈确认成就。
- 同时给出继续推进和继续优化两条清晰路径。

## 6. IncompleteResult 未连通提示
不要用“失败”。

显示：
- 光路未连通
- 光能不足 / 未抵达出口 / 被吸收
- 继续调整
- 重置

注意：
- 这个游戏是解谜游戏，未连通不一定要弹大结算页。
- 很多时候只需要在当前关卡内提示，让玩家继续调整。
- 提示应尽量贴近问题发生位置，例如在光线熄灭处或出口处给出轻提示。

## 7. Settings 设置页
包含：
- 音效
- 背景音乐
- 震动
- 隐私说明入口，预留

## 8. 基础流程总览
Loading / Boot  
→ Home 首页  
→ LevelSelect 关卡选择  
→ Gameplay 游戏页  
→ ClearResult 通关页 / IncompleteResult 未连通提示  
→ 下一关或返回关卡选择
