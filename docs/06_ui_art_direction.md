# 《折光回廊》UI 与美术方向

## 1. 总体风格
- 清爽
- 明亮
- 玻璃拟态
- 蓝紫渐变
- 柔和发光
- 大量留白
- 轻盈
- 现代
- 适合微信小游戏

## 2. 不要的风格
- 不要暗黑工业风。
- 不要赛博朋克。
- 不要高饱和杂色。
- 不要复杂棋盘格。
- 不要土味按钮。
- 不要写实废墟。
- 不要金属破败感。

## 3. 主游戏界面
结构：

顶部：
- 关卡编号
- 三星目标
- 当前镜子数量
- 重置按钮
- 提示按钮

中间：
- 平面光路关卡区域
- 左侧光源
- 右侧出口
- 镜子
- 障碍物
- 聚光点
- 光线路径

底部：
- 可用镜子工具栏
- 特殊道具栏
- 发射 / 预览按钮，如果需要

## 4. 视觉表现
- 光源：柔和发光入口。
- 出口：右侧发光光门。
- 镜子：半透明玻璃片，边缘有细微高光。
- 聚光点：小型发光晶体或圆形能量点。
- 分光聚能点：更精致的棱镜核心。
- 障碍物：柔和暗色半透明块，不要脏。
- 吸光块：黑紫色柔和吸光体。
- 光线：细而清晰，有轻微辉光和衰减变化。

## 5. 动效
- 拖动镜子时轻微放大
- 旋转镜子时有柔和角度吸附反馈
- 光线命中镜子时有小闪光
- 聚光点被点亮时扩散光圈
- 出口点亮时全局轻微闪光
- 通关时光路依次亮起

## 6. UI 设计原则
- 用少量按钮完成主要操作，避免遮挡关卡主体。
- 重要信息优先级从高到低依次为：出口状态、光能状态、当前镜子数量、三星目标。
- 卡片与按钮采用半透明玻璃面板，边缘高光细、阴影轻，不使用厚重描边。
- 文案长度控制在短句级别，保证竖屏小空间里一眼看懂。

## 7. 适配要求
- 主视觉和按钮布局优先适配手机竖屏。
- 顶部信息区高度要控制，不能压缩中间关卡区域。
- 底部工具栏需要兼顾单手操作，核心按钮应放在拇指容易触达的位置。
