# 棱镜光线 / Prism Lab 立项说明

## 项目背景

《棱镜光线 / Prism Lab》是一个面向微信小游戏平台的轻量单机益智项目。项目从 Web Canvas 玩法原型沉淀而来，核心验证已经明确：玩家通过摆放或调整光学元件，让光线经过反射、分光后命中目标点。

本项目同时承担两个目标：一是做出可以通过微信小游戏审核并正式上线的第一版产品；二是作为长期练习 Web Coding、TypeScript、Canvas 2D、小游戏工程分层的代码基地。

## 项目目标

- 做一个启动快、包体小、玩法清楚的单机益智小游戏。
- 第一版实现光源、镜子、三棱镜、目标点、关卡推进、基础 UI 与音效。
- 用 TypeScript 和 Canvas 2D 自研轻量框架，不依赖 Unity、Cocos、Phaser 等重型引擎。
- 保持玩法规则、渲染、输入、UI、音频、平台能力分层，便于后续持续开发。

## 项目边界

第一版只做本地单机体验。所有关卡、存档、设置优先使用本地数据，不请求后端，不依赖用户身份，不引导社交传播。

工程上以微信小游戏为目标平台，但核心玩法规则必须平台无关；未来可以复用到 Web、桌面调试页或其他 Canvas 环境。

## 第一版不做什么

- 不做登录、账号体系、用户资料读取。
- 不做排行榜、好友排行、云开发。
- 不接广告、支付、内购。
- 不接后端接口，不上传用户数据。
- 不采集用户隐私，不读取地理位置、通讯录、相册等敏感权限。
- 不做复杂皮肤、商业化成长系统或大规模关卡编辑器。

## MVP 成功标准

- 微信开发者工具可以导入项目并运行。
- 首批至少 3 个关卡可玩，后续扩展到 10 关。
- 光线传播、镜面反射、三棱镜分光、目标命中逻辑稳定。
- 白光进入同一个三棱镜只分裂一次，最多生成 3 条彩色光线，不能出现 9 条或更多的重复分裂 bug。
- UI 能完成开始游戏、关卡选择、重开、过关进入下一关。
- 第一版无网络、无广告、无登录、无隐私风险。

## 上线目标

第一阶段目标是提交微信小游戏体验版，完成真机测试和审核材料准备。上线版本应保持轻量、清晰、无敏感能力调用，优先降低审核和性能风险。

## 技术原则

- TypeScript 编写业务与规则逻辑。
- Canvas 2D 渲染，所有视觉资源优先矢量绘制或小尺寸音频/图片。
- 核心规则不依赖 wx API。
- wx API 只允许出现在 `minigame/src/platform/` 层。
- 规则系统只产出状态，不直接播放音效或操作 UI。
- UI、音效通过事件总线响应玩法事件。
- 代码以长期维护为目标，不写一次性 demo 式逻辑。

## 协作方式

仓库作为唯一事实来源。每次 Codex 任务需要在文档、代码、测试或清单中留下可审查产物。多对话协作时，所有结论必须回填到 GitHub：产品结论进入 docs，工程任务进入 prompts 或代码，审核事项进入上线清单和风险清单。
