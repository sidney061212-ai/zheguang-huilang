# 《折光回廊》核心玩法

《折光回廊》是固定平面关卡解谜游戏，不包含人物位移操控，也不是三维跑酷玩法。每一关的重点都在一张竖屏平面图上，玩家通过操作镜子改变光线路径，让左侧光源发出的光最终抵达右侧出口或光门。

## 1. 玩家看到什么
- 一个竖屏平面关卡。
- 左侧是光源，右侧是出口或光门。
- 中间有镜子、障碍物、固定镜、聚光点等元素。
- 光线路径会以清晰的可视化形式显示，让玩家知道当前是否接近通关。

## 2. 玩家做什么
- 玩家拖动镜子到合适位置。
- 玩家点击或用手势旋转镜子角度。
- 玩家观察光路是否能连接到出口。
- 玩家调整镜子数量和位置，争取更高评分。

## 3. 为什么需要镜子
- 光源与出口通常不在同一直线上。
- 中间常有障碍物或吸光块阻挡直线路径。
- 光线会不断衰减，绕路成本会直接体现在光能上。
- 只有通过镜子反射，玩家才能把光路改造成可通关、可优化的路径。

## 4. 为什么需要聚光点
- 光线会衰减，距离太远时会在中途熄灭。
- 聚光点可以补充光能，让光线继续延展。
- 聚光点不是强行规定的“必经点”，而是光路自然需要的能量补给点。
- 玩家在规划路线时，会主动思考是否值得绕去点亮聚光点，以换取更高剩余光能或更短镜子链路。

## 5. 基础通关流程
光源发光  
→ 玩家摆放镜子  
→ 光线反射绕过障碍  
→ 光线打中聚光点补充能量  
→ 光线继续延展  
→ 光线进入出口  
→ 通关结算

## 6. 失败情况
- 光线没有进入出口
- 光线能量耗尽
- 光线撞到障碍
- 光线被吸光块吸收
- 多束光没有全部到达汇光出口
- 颜色光进入错误出口

## 7. 成功反馈
- 出口被点亮
- 光路整体亮起
- 聚光点扩散光圈
- 弹出通关卡片
- 显示星级、用镜数量、剩余光能

## 8. 关卡结构原则
- 左侧某个位置固定放置光源，右侧某个位置固定放置出口或光门。
- 光源与出口通常存在错位、遮挡或光能不足问题，保证直射无法通关。
- 玩家拥有的镜子数量应略高于通关最低需求，这样既能让首次通关更稳，也能为三星优化留出空间。
- 后期加入分光聚能点后，一束光会被拆分成多束不同颜色的光，玩家需要继续围绕“路线规划 + 用镜优化 + 光能管理”这三个核心决策进行解题。
