# 《折光回廊》MVP 范围

## Prototype 0.1：1 关垂直切片

只做：
- 光源
- 出口
- 普通镜子
- 拖动镜子
- 旋转镜子
- 光线反射
- 光能衰减的基础显示
- 通关判断
- 重置关卡
- 简单通关结算

不做：
- 分光
- 颜色出口
- 商店
- 登录
- 广告
- 云排行榜
- 多皮肤
- 大量关卡

## Prototype 0.2：3 关玩法验证

加入：
- 连续反射
- 障碍物
- 简单关卡切换
- 三星目标

继续不做：
- 分光聚能点
- 汇光出口
- 颜色出口
- 商业化模块

## MVP 0.3：6 关基础 MVP

加入：
- 聚光点
- 光能衰减完整表现
- 固定镜
- 本地记录
- 失败提示（对玩家文案仍使用“光路未连通”等轻提示）
- 通关页

继续不做：
- 分光聚能点
- 汇光出口
- 颜色出口
- 首页包装图以外的大型装饰系统

## MVP 1.0：12 关首版

加入：
- 吸光块
- 分光聚能点
- 汇光出口
- 颜色出口
- 基础分享文案
- 简单首页
- 关卡选择页
- 设置页

边界说明：
- 即使到 MVP 1.0，也不默认引入登录、云排行榜、广告投放、商店和多人玩法。
- 首版目标是完成一套清晰、可复玩、方向统一的微信小游戏解谜产品，而不是追求功能堆叠。
