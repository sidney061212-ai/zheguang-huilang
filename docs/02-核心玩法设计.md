# 核心玩法设计

## 光源规则

光源是关卡中的固定起点，包含位置、方向、初始强度和颜色。第一版默认光源发出白光。光源本身不可移动，玩家通过场景中的光学元件改变光路。

## 光线传播规则

光线按射线方式传播，碰到最近的可交互对象后产生事件。每段光线记录起点、方向、颜色、强度、来源和分裂历史。强度可用于后续衰减或显示透明度，第一版优先保证路径正确。

光线模拟需要设置最大事件次数，防止反复反射或错误配置导致无限循环。

## 镜子反射规则

镜子具有位置、旋转角和长度。入射光命中镜面线段后，按照镜面法线执行反射：反射方向等于入射方向相对法线的镜像方向。镜子只改变方向，不改变颜色，不触发 UI 或音效；这些反馈由事件系统负责。

## 三棱镜分光规则

三棱镜是第一版最重要的风险点。规则如下：

- 只有 `white` 光线可以被三棱镜分裂。
- 白光第一次进入三棱镜时，固定生成 3 条彩色光线：`red`、`green`、`blue`。
- 同一条光线对同一个 `prismId` 只能触发一次分裂。
- 分裂出的彩色光线必须带有分裂历史，不能再次被同一个三棱镜分裂。
- 彩色光线再次碰到三棱镜时，第一版默认穿过或按后续明确规则折射，但绝不再次分裂。

## 三棱镜 bug 风险说明

历史原型中出现过“1 条白光进入三棱镜后产生 9 条光线”的问题。根因是分裂后的 3 条彩色光线仍会被同一个三棱镜当作新光线继续处理，每条再分裂成 3 条。正式工程中必须通过 `hasSplit`、`splitHistory`、`sourceId` 等字段保证分裂只发生一次。

## 目标点命中规则

目标点是圆形区域。任一有效光线段经过目标半径范围即可视为命中。后续可扩展颜色目标，例如只接受红光或蓝光。第一版目标点默认接受任意光色。

## 胜利条件

当前关卡至少一个目标点被有效光线命中时判定胜利。胜利后停止当前关卡输入，展示胜利弹窗，并允许进入下一关或重玩。

## 失败 / 重开机制

第一版不设置倒计时，不设置步数惩罚。玩家可以随时点击重开，恢复关卡初始配置。失败状态主要来自光线未命中、被墙体阻挡或超过最大模拟次数。

## 关卡递进逻辑

- 第 1 关：只使用直射目标，建立光源和目标概念。
- 第 2 关：加入镜子，建立反射概念。
- 第 3 关：加入三棱镜，建立白光分光概念。
- 后续关卡逐步加入障碍、多镜子、多目标、颜色目标。

每关只引入一个主要新概念，避免玩家同时学习多个规则。
