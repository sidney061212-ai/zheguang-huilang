# UI 视觉规范

## 视觉关键词

清爽、轻量、专注、明亮、带一点实验室感。界面应该服务解谜，不做夸张商业活动页，不做过度炫酷大屏风。

## 色彩方向

主背景使用浅色冷调，例如浅蓝灰或近白色。光线使用高辨识度颜色：白光偏青白，红绿蓝分光明确但不过度饱和。按钮和重点状态使用稳定的蓝色或青绿色。

## 首页 UI

首页应直接呈现游戏名称、开始按钮、关卡选择、设置入口。第一屏不做复杂宣传文案，不使用大面积渐变装饰。背景可以有轻量光线轨迹或三棱镜轮廓，保持包体小。

## 游戏内 UI

游戏页以 Canvas 玩法区为中心。顶部显示关卡编号、重开按钮、暂停或设置按钮。不要遮挡光路关键区域。按钮尺寸适合触摸，边距稳定。

## 胜利弹窗

胜利弹窗包含通关提示、下一关、重玩。弹窗半透明遮罩即可，不做复杂动画。胜利反馈要短促清晰，让玩家迅速进入下一关。

## 设置页

设置页第一版只包含音效开关、背景音乐开关、版本信息和返回按钮。不得加入账号、隐私授权、客服、支付等非 MVP 项。

## 按钮规范

按钮使用统一圆角、统一内边距和触摸反馈。主按钮强调，次按钮弱化。Canvas UI 按钮必须有命中区域，不只依赖文字尺寸。

## 动效原则

动效只用于状态确认，例如点击缩放、过关轻微闪光、目标命中脉冲。避免长动画、遮挡光路的粒子雨或影响低端机帧率的特效。

## 不做事项

- 不做复杂 3D、全屏炫光、重度粒子。
- 不使用大尺寸背景图堆视觉。
- 不把说明文字铺满游戏页。
- 不把 UI 做成活动运营页面。
